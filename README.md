# TreeSAPP
Phylogenetic Analysis from UBC iGEM 2025

## Distributed items
- `treesapp-maestro/`: a maestro workflow for working with EggNOG files

## Analyses
- `brenda/`: scripts to cross-reference BRENDA and UniProtKB/NCBI
- `gtdb_mapping/`: scripts to cross-reference UniProtKB taxonomy and GTDB data
